# ChatGPT Helper

Расширение для **Chrome / Edge** (Manifest V3), которое упрощает работу с [ChatGPT](https://chatgpt.com/): очередь запросов с фото, избранные промпты, галерея, закрепление сообщений, менеджер диалогов и опциональное облегчение длинных чатов.

> Документ поддерживается вместе с кодом: при добавлении функций сюда нужно дописывать описание.

---

## Установка

1. Откройте `chrome://extensions` или `edge://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку проекта.
4. Откройте [chatgpt.com](https://chatgpt.com/) и обновите вкладку (`Ctrl+Shift+R`).

После обновления самого расширения **всегда** перезагружайте вкладку ChatGPT — иначе может появиться ошибка `Extension context invalidated`.

На странице справа внизу — кнопка панели **CGH**. Над полем ввода — чипы промптов и кнопка **Очередь**.

---

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Alt+H` | Открыть / закрыть панель Helper |
| `Alt+Q` | Добавить текущий промпт (и вложения) в очередь |
| `Ctrl+Shift+Enter` | То же, что `Alt+Q` |
| `Enter` (пока ChatGPT отвечает) | Если включена настройка — добавить в очередь вместо «пустого» Enter |
| `Shift+клик` по чипу промпта | Вставить промпт и сразу отправить |

## Функции

### 1. Очередь запросов (с фото)

Позволяет ставить промпты в очередь и отправлять их по одному, когда ChatGPT свободен. **Вложения (фото/файлы) сохраняются вместе с пунктом очереди** (IndexedDB).

**Как пользоваться**

1. Напишите текст и/или прикрепите фото.
2. Нажмите кнопку **Очередь** над полем ввода (или `Alt+Q`).
3. Промпт очистится и попадёт в очередь; следующий уйдёт автоматически после ответа.

**Поведение**

- Фото привязаны **только к тому пункту**, в который вы их положили. Следующий запрос в очередь не подхватывает старые вложения.
- Очередь продолжает работать, если вкладка ChatGPT **открыта в фоне** (вы можете быть на другой вкладке). Вкладку chatgpt.com закрывать нельзя.
- Каждый пункт очереди привязан к **тому чату**, где его добавили. Если вы ушли в другой диалог, Helper вернётся в исходный чат перед отправкой.
- Пока модель отвечает, повторный клик по Send **не** используется как Stop — очередь ждёт завершения ответа.
- Перед отправкой с файлами ожидается готовность кнопки Send (загрузка вложений).
- Если поле пустое — кнопка **Очередь** открывает вкладку очереди в панели.
- В панели: пауза / продолжение, порядок пунктов, повтор при ошибке, очистка выполненных.

**Настройки**

- Автоочередь при занятом ChatGPT (`Enter` → в очередь).
- Автоотправка очереди, когда ChatGPT свободен.

---

### 2. Избранные промпты

Быстрые шаблоны рядом с полем ввода. Чипы **встроены в поток над composer** и едут вместе с изменением высоты поля.

**Как пользоваться**

- **★ Промпты** — открыть список справа. Сохранение только из панели («Новый промпт»), не по клику на чип.
- Клик по чипу на панели ввода — вставить текст в composer.
- `Shift+клик` — вставить и отправить.
- Во вкладке **Промпты**: создать / редактировать / удалить, экспорт и импорт JSON.
- **Пин** у промпта — показать или скрыть чип над полем ввода. Скрытые промпты остаются в списке справа.

Чипы рисуются поверх UI ChatGPT, но ниже модальных окон; дисклеймер *«ChatGPT can make mistakes…»* скрывается, чтобы не перехватывать клики.

---

### 3. Галерея изображений

Собирает **только картинки, которые сгенерировал ChatGPT** (сообщения ассистента). Фото, которые вы сами прикрепляете, в галерею не попадают.

**Возможности**

- Сетка превью, лайтбокс.
- Скачать одно фото с карточки или из лайтбокса.
- Выбрать несколько / скачать выбранные / скачать все.
- Копировать изображение в буфер.
- Фильтр «только этот чат», очистка галереи.
- Опциональное кэширование в IndexedDB (в фоне, не во время скана).

Сканирование лёгкое: без fetch на каждый кадр, превью рисуются сразу, выбор фото не перерисовывает всю сетку.

---

### 4. Закреплённые сообщения (Pin)

- Кнопка-пин стоит в конце нативного ряда действий сообщения (после «Поделиться»).
- Закреплённые видны во вкладке **Закреплённые**.
- **Перейти** — прыжок к сообщению в текущем чате или открытие нужного диалога.

---

### 5. Менеджер диалогов

Список чатов подгружается из ChatGPT (не только из видимого сайдбара) и обновляется при открытии вкладки и по кнопке **Обновить**.

Локально (в браузере) хранятся:

- папки (создание и редактирование в форме, не через `prompt`);
- звёздочки;
- теги и заметки;
- поиск по названию / тегам / заметкам.

С сервера ChatGPT, из текущего аккаунта:

- удалить чат;
- архивировать / вернуть из архива.

---

### 6. Caveman mode

Короткие ответы без воды: перед отправкой к вашему тексту добавляется директива (primer в первом сообщении чата, короткий reminder дальше).

- Включение и уровень (**Lite / Full / Ultra**) — в **Настройки**.
- На странице слева от кнопки Helper — компактный индикатор **CM** (клик открывает настройки).
- Директива видна в чате (так и задумано).
- Пока ChatGPT генерирует ответ и включена автоочередь, Enter по-прежнему кладёт запрос в очередь, а не в caveman-send.

### 7. Облегчение длинных чатов (Light trim)

Аналог идеи [ChatGPT LightSession](https://chromewebstore.google.com/detail/chatgpt-lightsession/fmomjhjnmgpknbabfpojgifokaibeoje): клиентская обрезка тяжёлых тредов.

**Что делает**

- Перехватывает ответы `GET /backend-api/…` с деревом `mapping` / `current_node`.
- Оставляет только последние **N** узлов активной ветки.
- Работает **локально в браузере**, без отправки данных на сторонние серверы.

**Настройки** (панель → Настройки, и popup)

| Опция | Описание | По умолчанию |
| --- | --- | --- |
| Включить облегчение | On / Off | Выкл. |
| Сколько сообщений оставлять | Лимит N | 10 |
| Сохранять system / tool | Не выкидывать служебные роли | Вкл. |

После включения обновите страницу чата, чтобы эффект применился к уже загруженному диалогу.

---

### 8. Настройки и язык

- Язык интерфейса: **Русский / English** (панель и popup).
- Автоочередь, автоотправка, кэш галереи, light trim.
- Акцентный цвет UI берётся из темы ChatGPT: `var(--theme-submit-btn-bg)`.

---

### 9. Popup расширения

Клик по иконке расширения:

- счётчики очереди / промптов / пинов;
- быстрый список избранных (вставка на активной вкладке ChatGPT или копирование);
- основные настройки, включая light trim;
- кнопка «Открыть ChatGPT».

## Хранение данных

Всё **локально** на устройстве:

| Данные | Где |
| --- | --- |
| Промпты, очередь (мета), пины, папки, настройки, индекс галереи | `chrome.storage.local` |
| Файлы очереди, кэш картинок | IndexedDB (`cgh-db`) |

Сторонним серверам расширение данные не отправляет.

## Производительность

Чтобы ChatGPT не тормозил из‑за Helper:

- MutationObserver смотрит в основном на `main`, а не весь `document` без нужды.
- Полный скан дисклеймера / галереи / диалогов не крутится на каждой мутации.
- Чипы не пересобираются при каждом изменении DOM (избегаем мигания hover).
- Light trim по умолчанию выключен — включайте сознательно на очень длинных чатах.

Если после обновления расширения страница ведёт себя странно — сделайте hard refresh вкладки ChatGPT.

---

## Известные ограничения

- UI ChatGPT часто меняется: селекторы composer / Send / Stop могут потребовать правки в `lib/dom.js`.
- Очередь с фото зависит от того, как ChatGPT принимает программную установку `input[type=file]`.
- Light trim режет **отображаемое** дерево переписки в ответе API; это не удаляет историю на серверах OpenAI.
- После Reload расширения старый content script на открытой вкладке «умирает» — нужна перезагрузка страницы.
