# ChatGPT Helper

Расширение для Chrome / Edge: очередь запросов (включая фото), избранные промпты, галерея, закрепление сообщений и менеджер диалогов.

## Установка

1. Откройте `chrome://extensions` (или `edge://extensions`).
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите эту папку.

Откройте [chatgpt.com](https://chatgpt.com/) — справа появится зелёная кнопка **CGH**.

## Возможности

| Функция | Как пользоваться |
| --- | --- |
| **Очередь** | Прикрепите фото, напишите текст, нажмите **+ очередь** или `Alt+Q`. Если ChatGPT ещё отвечает, `Enter` тоже кладёт запрос в очередь. |
| **Избранные промпты** | Чипы над полем ввода. Клик — вставить, Shift+клик — сразу отправить. ★ Сохранить — текущий текст в избранное. |
| **Галерея** | Картинки из чатов собираются во вкладке «Галерея». |
| **Пины** | Наведите на сообщение → 📌. Список закреплённых — в панели. |
| **Диалоги** | Папки, звёзды, теги и заметки поверх списка чатов ChatGPT. |

Горячие клавиши: `Alt+H` — панель, `Alt+Q` — в очередь.
